# Student Attendance & Performance Analysis

## 📊 Project Overview

This project analyzes student attendance, study hours, assignment completion, and academic performance using Microsoft Excel.

The goal is to identify patterns and relationships between these factors and students' marks.

## 🛠️ Tools Used

- Microsoft Excel
- Excel formulas and functions
- Data analysis
- Data visualization

## 🔎 Analysis Performed

The project includes:

- Average attendance
- Average marks
- Average study hours
- Attendance-based performance comparison
- Study-hours-based performance comparison
- Assignment-completion-based performance comparison
- Highest and lowest marks
- Correlation analysis

## 📈 Key Findings

- Students with 75% or higher attendance had an average mark of **73.30%**, compared with **70.40%** for students below 75%.
- Students studying 8 or more hours per week had an average mark of **76.80%**, compared with **66.50%** for students studying below 8 hours.
- Students completing 5 or more assignments had an average mark of **73.50%**, compared with **62.60%** for students completing fewer than 5 assignments.
- Study hours had the strongest correlation with marks at **0.60**.
- Assignment completion had a correlation of **0.50** with marks.
- Attendance had a correlation of **0.30** with marks.

## 📊 Dashboard

The Excel dashboard contains:

- Key performance metrics
- Attendance comparison
- Study-hours comparison
- Assignment comparison
- Project conclusion

## 💡 Conclusion

Overall, the analysis shows a positive relationship between attendance, study hours, assignment completion, and academic performance in this dataset.

However, correlation shows association and does not by itself prove that one factor causes another.
